Build a clean, mobile-first in-app chat feature for my app called “Decoded Faith Empires.”

PURPOSE:
This chat is not a generic chatbot. Its purpose is to help users understand the Bible and grow spiritually. It should feel like a warm, wise, scripture-centered faith guide.

CORE EXPERIENCE:
Create a chat interface where users can ask questions like:
- “What does this Bible verse mean?”
- “Help me understand Romans 8”
- “What does the Bible say about anxiety?”
- “Give me a prayer for fear”
- “How can I grow closer to God?”
- “Give me scriptures about healing”
- “Summarize this chapter in simple language”

CHAT BEHAVIOR:
The assistant should:
1. Answer in a biblically grounded, encouraging, easy-to-understand way
2. Prioritize scripture-based responses
3. Explain things simply, like a trusted Bible teacher
4. Be warm, peaceful, and spiritually mature in tone
5. Avoid sounding robotic, preachy, or overly academic
6. Never replace pastoral, medical, legal, or crisis support
7. Encourage prayer, reflection, and deeper study
8. When possible, include:
   - a direct answer
   - relevant Bible verses
   - a short explanation
   - one practical life application
   - an optional short prayer

Build a beautiful, minimal, modern chat UI with:
- mobile-first responsive layout
- message bubbles for user and assistant
- input field fixed at bottom
- send button
- loading state while assistant is responding
- auto scroll to newest message
- clean typography
- soft faith-centered design aesthetic
- suggested prompt chips above the input, such as:
  - Explain this verse
  - Scriptures for anxiety
  - Help me pray
  - Bible study help
  - Grow spiritually

FEATURES:
1. Chat screen with conversation history in current session
2. Suggested starter prompts
3. “Clear chat” button
4. Optional save/favorite message feature
5. Copy response button
6. Verse reference styling so Bible verses stand out visually
7. Error handling for failed responses
8. Empty state with welcome text:
   “Ask anything about the Bible, prayer, faith, or spiritual growth.”

Add a system prompt or instruction layer so the assistant:
- stays focused on Bible understanding and spiritual growth
- does not drift into random general-purpose chat
- does not present opinions as absolute doctrine when multiple Christian interpretations may exist
